# Input data

`meta.tsv` (sample, patient, region, batch, VP-008 flag) is included. It is also regenerated by `code/qc.py`.

Download the following public files into this folder:

| File | Source |
|---|---|
| `GSE311770_all_samples_rsem_gene_counts.tsv.gz` | GEO series GSE311770, supplementary file |
| `GSE65127_series_matrix.txt.gz` | GEO series GSE65127, series matrix |
| `GPL570-55999.txt` | GEO platform GPL570, full annotation table |
| `HALLMARK_INTERFERON_GAMMA_RESPONSE.v2026.2.Hs.json` | MSigDB, Hallmark collection, JSON export |
| `ncbi_gene_ensembl_map.tsv` | Built from NCBI `Homo_sapiens.gene_info.gz` with `code/make_gene_map.py` |

GEO: https://www.ncbi.nlm.nih.gov/geo/
MSigDB: https://www.gsea-msigdb.org/gsea/msigdb/
NCBI gene_info: https://ftp.ncbi.nlm.nih.gov/gene/DATA/GENE_INFO/Mammalia/Homo_sapiens.gene_info.gz
